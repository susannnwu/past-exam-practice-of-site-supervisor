# 工地主任歷屆試題模擬練習

工地主任歷屆試題練習網站，方便在電腦、平板或手機上複習與模擬作答。

## [開始練習 →](https://susannnwu.github.io/past-exam-practice-of-site-supervisor/)

開啟網站即可使用，不需安裝軟體。

## 功能

- 依年份、考試場次及試卷選擇練習；同一情境題集中呈現。
- 可搜尋題幹、選項與共用情境的文字，跨卷挑題組成自組練習。
- 中途自動儲存、暫停與繼續作答；同一試卷可多次練習。
- 90 分鐘正數計時，時間到會提醒，不強制交卷。
- ⚑ 標記需要再檢查的題目，✓ 標記已確認的題目。
- 畫面旁提供計算紙，可書寫、擦除、移動、縮放及下載筆跡。
- 交卷後查看得分與答題結果一覽，點題號即可跳到對應檢討。
- 查看歷次作答、錯題及已標記題目；歷次紀錄保留當次交卷的標記。
- 提供 Light／Dark／System 顯示模式，預設跟隨裝置設定。

## 如何使用

1. 點選上方「開始練習」，挑選年份、場次與試卷。
2. 按「開始模擬」進入作答畫面。
3. 需要稍後繼續時，按「儲存並暫停」或「回到選卷」。
4. 完成後按「交卷並檢討」，確認後查看成績。每題 2 分，50 題滿分 100 分；送分題會另外標示。
5. 在選卷畫面查看該卷歷次紀錄，或從「錯題紀錄」複習。交卷後也可按「再做一次」。

### 搜尋組卷

1. 開啟「搜尋組卷」，輸入關鍵字，可再依年份、場次和 A／B 卷篩選。結果顯示命中位置、原卷題號與 PDF 頁碼。圖表與掃描圖中的文字可能無法搜尋。
2. 可逐筆加入，或用「加入本頁」與「加入全部搜尋結果」批次加入。兩個按鈕都會套用目前篩選，並顯示可新增的題數。情境題整組加入、整組移除，已選題目只計一次。更改關鍵字或篩選時，已選題目會保留在題單。
3. 在「查看題單」可用「挑題卷別」只顯示 A 或 B 卷，再勾選要分類的題目，選擇既有題組或新增命名題組，並按「儲存勾選題目」。未勾選的題目會留在題單。「開始練習」使用目前顯示的卷別。「清空題單」在確認後移除目前所有選題，保留已儲存題組及作答紀錄。
4. 在「已儲存題組」按「挑題分類」，同樣可依卷別挑選要移到其他題組的單題或整組情境題。目的題組已經有的題目只計一次。分類前的作答進度與成績仍使用當時的題目與順序。
5. 從題單直接開始練習，或從「已儲存題組」開啟有名稱的題組。臨時組卷也能從「臨時組卷紀錄」續答。交卷後可查看完整檢討、只看錯題，或用同一題單再做一次。自組練習的成績與來源試卷分開記錄。

## 答題結果怎麼看

- ○／綠色：答對。
- ✕／紅色：答錯。
- —／淺色：未作答。
- ★：送分題。
- ⚑ 與 ✓：當次交卷時的待檢查／已確認標記。

下方檢討保留全部選項，正確選項以綠色標示，選錯的選項以紅色標示；「答題結果一覽」按鈕可快速返回上方。

## 作答紀錄與資料保存

題組、答案、進度、成績、標記及計算紙保存在目前使用的瀏覽器，不會自動同步到其他裝置、瀏覽器或網址。請固定使用同一裝置、瀏覽器與網站網址續答。

清除瀏覽器網站資料或使用網站的「清除全部紀錄」，會影響已儲存的紀錄；網站清除功能會連動清除錯題、歷次作答與未完成進度。

## 題庫

目前提供 48 張試卷、2,400 題。題目與答案依歷屆試卷資料整理，部分掃描試卷尚未收錄。作答頁提供原始 PDF 連結，遇到疑義時可開啟原卷核對。
