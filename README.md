# Past Exam Practice of Site Supervisor

工地主任歷屆試題練習網站，方便在電腦、平板或手機上複習與模擬作答。

## [開始練習 →](https://susannnwu.github.io/past-exam-practice-of-site-supervisor/)

開啟網站即可使用，不需安裝軟體。

## 功能

- 依年份、考試場次及試卷選擇練習；同一情境題集中呈現。
- 中途自動儲存、暫停與繼續作答；同一試卷可多次練習。
- 90 分鐘正數計時，時間到會提醒，不強制交卷。
- ⚑ 標記需要再檢查的題目，✓ 標記已確認的題目。
- 畫面旁提供計算紙，可書寫、擦除、移動、縮放及下載筆跡。
- 交卷後查看得分與答題結果一覽，點題號即可跳到對應檢討。
- 查看歷次作答、錯題及已標記題目；歷次紀錄保留當次交卷的標記。
- 提供 Light／Dark／System 顯示模式，預設跟隨裝置設定。

## 如何使用

1. 點選上方「開始練習」，挑選年份、場次與試卷。
2. 按「開始模擬」進入作答畫面。
3. 需要稍後繼續時，按「儲存並暫停」或「回到選卷」。
4. 完成後按「交卷並檢討」，確認後查看成績。每題 2 分，50 題滿分 100 分；送分題會另外標示。
5. 在選卷畫面查看該卷歷次紀錄，或從「錯題紀錄」複習。交卷後也可按「再做一次」。

## 答題結果怎麼看

- ○／綠色：答對。
- ✕／紅色：答錯。
- —／淺色：未作答。
- ★：送分題。
- ⚑ 與 ✓：當次交卷時的待檢查／已確認標記。

下方檢討保留全部選項，正確選項以綠色標示，選錯的選項以紅色標示；「答題結果一覽」按鈕可快速返回上方。

## 作答紀錄與資料保存

答案、進度、成績、標記及計算紙保存在目前使用的瀏覽器，不會自動同步到其他裝置、瀏覽器或網址。請固定使用同一裝置、瀏覽器與網站網址續答。

清除瀏覽器網站資料或使用網站的「清除全部紀錄」，會影響已儲存的紀錄；網站清除功能會連動清除錯題、歷次作答與未完成進度。

## 題庫

目前提供 48 張試卷、2,400 題。題目與答案依歷屆試卷資料整理，部分掃描試卷尚未收錄。作答頁提供原始 PDF 連結，遇到疑義時可開啟原卷核對。
